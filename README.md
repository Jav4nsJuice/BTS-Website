# BTS Website

Business Tech Solutions - Software Development Company Website

## Features

- **Home Page** with Mission and Vision sections
- **Contact Us Page** with contact form and company information
- Modern, responsive design with purple/indigo theme matching the BTS brand
- Built with React and TypeScript
- Fast development with Vite

## Getting Started

### Prerequisites

- Node.js (v16 or higher)
- npm or yarn

### Installation

1. Install dependencies:
```bash
npm install
```

2. Start the development server:
```bash
npm run dev
```

3. Open your browser and navigate to `http://localhost:5173`

### Build for Production

```bash
npm run build
```

The built files will be in the `dist` directory.

### Preview Production Build

```bash
npm run preview
```
